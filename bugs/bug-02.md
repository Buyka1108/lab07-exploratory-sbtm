# BUG-02: Он баганын утгууд мянгатын таслалтай харагдана

Орчин: Уншлагын жагсаалт v2.0; Microsoft Edge 155.0.4283.45 (64-bit), Windows; сервер Ubuntu/WSL2, Node.js v22.22.1; 2026-10-15.

Урьдчилсан нөхцөл: Ажиллаж байгаа серверийг Ctrl+C-ээр зогсоож, node app.js командаар шинээр асаасан. Анхны 3 номтой төлөв.


## Дахин гаргах алхам
1. Урьдчилсан нөхцөлийн дагуу аппыг шинээр асаана.
2. http://localhost:3000 хаягийг нээнэ.
3. Анхны гурван номын «Он» баганыг ажиглана.

Хүлээгдэж байсан: Спецификациар он энгийн тоогоор буюу 1971, 2008, 1999 гэж харагдана.

Бодит үр дүн: Он 1,971; 2,008; 1,999 гэж таслалтай харагдана.

Ноцтой байдал: Cosmetic — оны харагдах формат спецификациас зөрсөн.

Олдсон аялал: Supermodel (GUI).
