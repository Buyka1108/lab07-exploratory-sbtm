# BUG-04: Буруу JSON бүхий POST хүсэлтэд 400-ийн оронд 200 OK буцаана

Орчин: Уншлагын жагсаалт v2.0; Microsoft Edge 155.0.4283.45 (64-bit), Windows; сервер Ubuntu/WSL2, Node.js v22.22.1; 2026-10-15.

Урьдчилсан нөхцөл: Ажиллаж байгаа серверийг Ctrl+C-ээр зогсоож, node app.js командаар шинээр асаасан. Анхны 3 номтой төлөв.


## Дахин гаргах алхам
1. Урьдчилсан нөхцөлийн дагуу аппыг шинээр асааж, серверийг ажиллаж байгаа чигээр үлдээнэ.
2. Өөр Ubuntu терминал нээнэ.
3. Дараах командыг ажиллуулна:

```bash
curl -sS -i -X POST http://localhost:3000/api/books \
  -H 'Content-Type: application/json' \
  --data-binary 'буруу оролт'
```

4. HTTP статус болон хариуны body-г ажиглана.

Хүлээгдэж байсан: Спецификациар буруу JSON биетэй POST хүсэлтэд HTTP 400 буцаана.

Бодит үр дүн: HTTP/1.1 200 OK статус, {"result":"OK"} body буцаана.

Ноцтой байдал: Major — API хүчингүй JSON хүсэлтийг амжилттай гэж мэдээлж, клиентэд буруу үр дүн өгнө.

Олдсон аялал: Saboteur (API).
