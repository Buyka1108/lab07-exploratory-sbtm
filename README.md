## Аппыг ажиллуулах

Багшийн өгсөн app.rar архиваас app.js файлыг задлан лабораторийн хавтсанд байрлуулна.
app.js нь багшийн материал учраас энэ репод оруулаагүй.
Нэмэлт npm сан суулгах шаардлагагүй.

    node app.js

Браузерт http://localhost:3000 хаягийг нээнэ.
Серверийг Ctrl+C-ээр зогсоож дахин асаахад анхны 3 номтой төлөвт орно.
Bug report бүрийн өмнө аппыг шинээр асаана.
